# HigherLowerGame
This is a quick game I made in highschool. You have 6 discard piles and a draw pile. You do not know what the next card will be, but you have to guess if it will be higher or lower than the card on one of your discard piles. If you guess wrong, that pile is removed and then you have 5 discard piles left. Left click guesses lower, right does higher.
